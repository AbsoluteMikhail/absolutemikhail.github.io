Недоступность инструментов не мешает независимой работе по исходникам; не создавать заменяющие базы и не переключаться на базы других проектов.
- Постановка задачи и подготовка документации не запускают исполнителей: нужно поручение «делай», «запускай» или равнозначное. «Проверь» не меняет статусы; «прими» разрешает техническую приёмку. Родительскую задачу Vikunja закрывает владелец. Приёмка не разрешает коммит или публикацию.

## Исходники и архитектура

React 18, TypeScript, Vite, React Router, Tailwind CSS, Framer Motion, Lucide. Статический GitHub Pages с пререндерингом. Использовать npm и `package-lock.json`; не менять стек и зависимости попутно.

| Область | Файлы |
| --- | --- |
| Маршруты и запуск | `src/App.tsx`, `src/main.tsx` |
| Страницы и секции | `src/pages/`, `src/components/` |
| Контент и каталоги | `src/content/`, `src/constants/` |
| Тема и UI | `src/index.css`, `tailwind.config.ts`, `src/components/ui/README.md` |
| Медиа | `src/assets/`; постоянные публичные URL — `public/` |
| SEO и пререндеринг | `src/constants/routeMetadata.js`, `src/components/RouteMetadata.tsx`, `src/entry-server.tsx`, `scripts/prerender.mjs` |
| Тесты и деплой | `src/test/`, `vitest.config.ts`, `.github/workflows/deploy.yml` |

- Редактировать исходники, не `dist/` и `dist-ssr/`. Сохранять UTF-8 и регистр путей для Linux.
- Продолжать существующие компоненты и подходы. Для импортов из `src` — `@/`, для классов — `cn` из `src/lib/utils.ts`; общие кнопки, заголовки и плашки — из `src/components/ui/` по его README.
- Сохранять ленивую загрузку страниц; не тянуть тяжёлые сцены и плееры на главную без необходимости.
- Пререндеринг должен работать без браузерных API; обращаться к ним в эффектах, обработчиках или с проверкой окружения. Основной HTML должен читаться без JavaScript, включая контент с Framer Motion.
- `src/main.tsx` намеренно сохраняет готовый HTML до загрузки страницы и затем использует `createRoot`. Не заменять на `hydrateRoot` попутно.

## Интерфейс

- Проверять изменённые экраны на 360–390, 768 и 1440 px: без обрезаний, наложений и горизонтальной прокрутки. Сохранять клавиатурный фокус, подписи и `alt`; в диалогах — Escape, удержание и возврат фокуса.
- Учитывать `prefers-reduced-motion` и сенсорные устройства; курсор и анимации не должны мешать действиям, важный контент не должен зависеть только от hover.
- Резервировать место под изображения; медиа ниже первого экрана загружать лениво, главное изображение — без задержки.
- После правок навигации или контактов проверять мобильное меню, переход к секции с другой страницы, открытие и закрытие контактов.

## Маршруты, SEO и приватность

- Канонический адрес — `https://gamepunk.ru`. Сохранять URL и якоря; при изменении обновлять ссылки. Новый маршрут согласовать с метаданными, `src/main.tsx`, `src/entry-server.tsx` и пререндерингом; `*` оставлять последним.
- Проверять title, description, canonical, Open Graph и robots в итоговом HTML. Sitemap генерируется автоматически. Сохранять `noindex` служебных страниц и исключение аналитики для `/malena/privacy`.
- Проверять прямое открытие и обновление вложенного URL с учётом `public/404.html` и GitHub Pages.
- Политика и условия — `/privacy` и `/terms`. Аналитика только после согласия через `PrivacyControls`; отказ и отзыв останавливают счётчики. Выбор хранится 180 дней. Не возвращать безусловные счётчики в HTML и не выдумывать сроки хранения у внешних сервисов.

## Академия

- Перед изменением публичной Академии читать [руководство контента](src/content/academy/README.md). Сохранять `/academy`, ссылки из меню и главной, обратный переход на сайт. Анонсы на главной опираются на опубликованные материалы и не загружают весь каталог.
- `updated: YYYY-MM-DD` менять при содержательном обновлении материала, не при редизайне или пересборке. «Свежее» учитывает последнюю дату курса и уроков.
- Направления остаются выше «Свежего», включая незаполненные. На телефоне список уроков и оглавление сворачиваются и доступны без JavaScript.
- Каталог хранит метаданные; текст выбранного материала загружает `academyContent`. Общие маршруты и SEO — `academyRoutes` / `resolvePageMetadata` для браузера и пререндеринга. H1 задаёт шаблон, Markdown начинается с текста или H2.
- Авторский учебный код и Blueprint-примеры — 0BSD (`public/academy-code-license.txt`), включая коммерческое использование без обязательного упоминания автора. Это не лицензия на сторонний код, игры и остальные материалы.

## Проверки и публикация

Команды — из корня, проверки — по изменению:

| Изменение | Проверка |
| --- | --- |
| Только инструкции или документация вне страниц | Перечитать diff, проверить ссылки и команды, `git diff --check` |
| TypeScript / TSX | `npx tsc --noEmit -p tsconfig.app.json` и ESLint затронутых файлов |
| Поведение и маршруты | Затронутые тесты: `npm test -- src/test/имя.test.tsx` |
| Код, стили, публичный контент, зависимости | `npm run build` (клиент, SSR, пререндеринг) |
| Интерфейс | Браузер через `npm run dev`; итоговая сборка — `npm run preview` |

- Полная проверка CI — `npm run check` (типы, ESLint, тесты); `npm run lint` проверяет только `src/`. Сборка не заменяет TypeScript и браузер. Тесты добавлять для поведения и регрессий, не для простой правки текста или отступа.
- Перед сдачей просмотреть diff и `git diff --check`. Непроверенное назвать прямо; старые ошибки отделять от внесённых своей правкой.
- Коммит, push и публикация — по поручению пользователя. **Push в `master` публикует сайт** через `.github/workflows/deploy.yml`: до него выполнить проверки, после — проверить workflow и доступность страницы.
- Ветки — `codex/`, если не указано иное. Не коммитить сборки, временные файлы, локальные материалы и секреты; без явного разрешения не делать разрушительных откатов и force push.
