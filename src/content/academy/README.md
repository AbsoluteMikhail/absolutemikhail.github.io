# Academy Content Guide

Эта папка содержит контент публичного раздела `/academy`.

Раздел работает как простой docs-движок: React-код один раз рисует направления, карточки материалов, меню и типографику, а курсы и уроки добавляются обычными Markdown-файлами.

## Направления и форматы

Направление отвечает на вопрос «о чём материал», а формат — «что это». Сейчас в Academy есть четыре направления:

- `cpp` — C++;
- `unreal-engine` — Unreal Engine;
- `ai` — Нейросети;
- `tools` — Инструменты и IT.

Один материал может относиться сразу к нескольким направлениям. Например, курс по C++ в Unreal Engine указывает `topics: unreal-engine, cpp`.

Поле `format` содержит видимое название формата: `Курс`, `Подборка`, а в будущем — `Статья`, `Гайд`, `Сравнение`, `Проект` или `Серия`.

## Быстрая структура

```txt
src/content/academy/
  README.md
  course-slug/
    index.md
    01-first-lesson.md
    02-second-lesson.md

public/academy/
  course-slug/
    image.jpg
    project-files.zip
```

## Как добавить новый курс

1. Создай папку курса внутри `src/content/academy`.

   ```txt
   src/content/academy/my-new-course/
   ```

2. Добавь в нее `index.md`. Это главная страница курса.

   ```md
   ---
   type: course
   slug: my-new-course
   title: Название курса
   description: Короткое описание курса для карточки и шапки.
   format: Курс
   project: Название сквозного проекта
   tags: Unreal Engine, C++, Gameplay
   topics: unreal-engine, cpp
   status: В работе
   order: 2
   updated: 2026-09-02
   cover: /academy/my-new-course/cover.jpg
   coverAlt: Текстовое описание обложки
   ---

   Основное описание курса.

   ## Для кого курс

   - Пункт 1
   - Пункт 2
   ```

3. Открой `/academy`. Карточка курса появится автоматически.

## Дата обновления и лента «Свежее»

- В метаданных курса и урока используется `updated: YYYY-MM-DD` — дата содержательного обновления. При изменении урока обновляй его дату; при изменении описания или состава подборки — дату в `index.md`.
- Карточка курса показывает самую позднюю дату из `index.md` и его уроков. Лента «Свежее» и списки направлений сортируются по этой дате от новых к старым.
- При равных датах сохраняется порядок `order`, затем по названию. Материалы без даты идут после датированных; дату для них не выдумывать. Порядок уроков внутри курса по-прежнему задаёт `order`.
- Используй фактическую дату обновления, а не дату пересборки сайта или правки общего дизайна. Начальные даты текущих материалов сверены с историей Git соответствующих каталогов.
- Некорректная дата останавливает сборку и указывает файл. Формат одинаковый для клиента и пререндеринга.

## Как добавить урок

Создай `.md` файл в папке курса:

```txt
src/content/academy/my-new-course/01-first-lesson.md
```

Минимальный шаблон урока:

```md
---
type: lesson
course: my-new-course
title: Название урока
description: Короткое описание урока.
block: Блок 1 - Название блока
video: 1
order: 1
updated: 2026-09-02
pain: Главная боль, которую решает урок
mainIdea: Главная мысль урока.
youtube: https://youtu.be/VIDEO_ID
cover: /academy/my-new-course/cover.jpg
coverAlt: Текстовое описание обложки урока
videoIntro: Короткое пояснение перед основным видео.
---

## Главная боль

> Формулировка боли.

## Зачем это существует?

Текст урока.

## Темы

- Тема 1
- Тема 2
- Тема 3
```

После этого урок появится:

- в списке уроков курса;
- в левом сайдбаре;
- по адресу `/academy/my-new-course/01-first-lesson`.

## Frontmatter-поля

Frontmatter - это блок между `---` в начале файла.

Для курса:

- `type: course` - обязательный тип документа.
- `slug` - URL курса. Пример: `ue-cpp-blueprint-devs`.
- `title` - название курса.
- `description` - описание для карточки и шапки.
- `format` - видимый формат материала. Например: `Курс` или `Подборка`.
- `project` - сквозной проект курса, если есть. Пример: `Greybox Arena`.
- `tags` - теги карточки курса через запятую. Пример: `Unreal Engine, C++, Gameplay`.
- `topics` - направления Academy через запятую. Допустимые значения: `cpp`, `unreal-engine`, `ai`, `tools`.
- `status` - статус курса. Например: `В работе`, `Тестовый курс`, `Опубликован`.
- `order` - порядок курса на `/academy`.
- `cover` - публичный путь к обложке курса. Рекомендуемое соотношение сторон `16:9`.
- `coverAlt` - содержательное текстовое описание обложки для доступности.

Для урока:

- `type: lesson` - обязательный тип документа.
- `course` - slug курса, к которому относится урок.
- `title` - название урока.
- `description` - короткое описание.
- `block` - блок/модуль курса. Уроки с одинаковым `block` группируются вместе.
- `video` - номер видео или внешний номер урока.
- `order` - порядок урока внутри курса.
- `pain` - главная боль урока.
- `mainIdea` - главная мысль урока.
- `youtube` - ссылка на основное YouTube-видео урока. Если поле есть, видео автоматически появится в шапке урока.
- `videoIntro` - короткий текст перед основным видео, например пояснение о разнице видео- и текстовой версии.
- `cover` - публичный путь к обложке урока. Если обложка совпадает с курсом, путь можно повторить.
- `coverAlt` - содержательное текстовое описание обложки.

## Markdown-разметка

Поддерживается базовая разметка:

````md
## H2
### H3

Обычный текст с **жирным**, *курсивом* и `inline code`.

- Список
- Еще пункт

1. Нумерованный список
2. Еще пункт

> Цитата или главная мысль.

```cpp
UPROPERTY(EditAnywhere)
float Damage = 10.0f;
```

[Ссылка](https://example.com)
![Картинка](/academy/course-slug/image.jpg)

| Колонка | Значение |
|---|---|
| Пример | 42 |
````

## Callout-блоки

Можно добавлять выделенные блоки:

```md
:::note
Обычная заметка.
:::

:::tip
Практический совет.
:::

:::warning
Важное предупреждение.
:::
```

## YouTube-видео

Основное видео урока лучше добавлять в frontmatter:

```md
---
type: lesson
course: my-new-course
title: Название урока
youtube: https://youtu.be/VIDEO_ID
---
```

Так видео автоматически появится перед текстом урока в адаптивном `16:9` контейнере.

Если на странице нужно несколько видео, используй Markdown-блок:

```md
:::youtube Название видео
https://youtu.be/VIDEO_ID
:::
```

Поддерживаются обычные ссылки YouTube:

- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://www.youtube.com/embed/VIDEO_ID`
- `https://www.youtube.com/shorts/VIDEO_ID`

## Адаптивная flow-схема

Для простой архитектурной инфографики используй `flow`. Каждая строка — слой, символ `|` делит слой на несколько узлов:

```md
:::flow Архитектура системы
Болото | Яд | Ускорение
Speed Manager Component
Character Movement
:::
```

Схема адаптируется под ширину экрана и остаётся доступной как текст, поэтому её предпочтительнее использовать вместо растровой картинки для простых потоков данных.

## Интерактивные BlueprintUE-графы

Постоянную публичную или `Unlisted`-ссылку BlueprintUE можно встроить так:

```md
:::blueprintue RecalculateSpeed
https://blueprintue.com/blueprint/BLUEPRINT_ID/
/academy/course-slug/recalculate-speed.jpg
Функция RecalculateSpeed — резервный скриншот
:::
```

Первая строка блока — постоянная HTTPS-ссылка с `blueprintue.com`, вторая — необязательный локальный скриншот, третья — его alt-текст. Если скриншот добавлен, он показывается первым, а читатель может переключиться на интерактивный `/render/` viewer кнопкой «Граф». При ошибке загрузки iframe renderer также попробует вернуть локальную копию. Для долговечных материалов выбирай публикацию без срока удаления.

## Картинки и файлы

Контентные ассеты лучше класть в `public/academy/<course-slug>/`.

Пример:

```txt
public/academy/ue-cpp-blueprint-devs/greybox-arena.jpg
public/academy/ue-cpp-blueprint-devs/project-files.zip
```

Использование в Markdown:

```md
![Greybox Arena](/academy/ue-cpp-blueprint-devs/greybox-arena.jpg)

[Скачать проект](/academy/ue-cpp-blueprint-devs/project-files.zip)
```

При клике обычные Markdown-изображения и резервные Blueprint-скриншоты открываются во встроенном полноэкранном просмотрщике. Отдельная вкладка браузера для увеличения не используется.

## Адреса страниц

Если курс лежит здесь:

```txt
src/content/academy/ue-cpp-blueprint-devs/index.md
```

то страница курса будет:

```txt
/academy/ue-cpp-blueprint-devs
```

Если урок лежит здесь:

```txt
src/content/academy/ue-cpp-blueprint-devs/01-ue-cpp-environment.md
```

то страница урока будет:

```txt
/academy/ue-cpp-blueprint-devs/01-ue-cpp-environment
```

## Важные ограничения

- H1 выводится шаблоном из `title`. Не повторяй его в Markdown: начинай с вводного текста или H2. Старые ссылки на название сохраняются через `id` главного заголовка.
- Служебные инструкции по добавлению файлов, видео и уроков хранятся здесь, а не в тексте публичного курса.
- MDX-компоненты пока не подключены, только Markdown и custom callout-синтаксис.
- Если нужен новый тип блока, например Download button, его нужно добавить в renderer: `src/components/academy/MarkdownContent.tsx`.

## Загрузка, навигация и SEO

- `plugins/academy-content.ts` выдаёт только frontmatter по запросу `?academy-meta`. `src/lib/academy.ts` строит из него лёгкий каталог; корневой `README.md` не входит в каталог.
- `src/lib/academyContent.ts` загружает текст выбранного Markdown-файла отдельным модулем, объединяет одновременные запросы и кэширует успешный результат. Ошибку можно повторить; не добавляй `eager: true` к загрузке текстов.
- При прямом открытии страницы клиент сохраняет готовый HTML до загрузки выбранного текста. Сервер предварительно загружает тот же материал перед `renderToString`; поэтому статья и меню остаются доступны без JavaScript.
- `academyRoutes.ts` определяет страницу и её метаданные; `resolvePageMetadata.ts` используется клиентом и пререндерингом. Названия и описания берутся из frontmatter, неизвестные адреса получают `noindex`.
- На главной сначала идут направления, затем «Свежее». На телефоне список уроков и оглавление открываются через нативные `details`; на широком экране доступны боковые колонки.
- `npm run build` дополнительно проверяет повреждённый Unicode, единственный H1, уникальность title и цели ссылок оглавления в готовом HTML Академии. Ошибка должна исправляться в исходниках, а не в `dist`.
