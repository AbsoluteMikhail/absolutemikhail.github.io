# Wwise + Unreal Engine: первый заход в игровой звук

Полный рабочий набросок вводного курса. Дата подготовки: 23 сентября 2026 года. В каталог Академии и сборку сайта не подключён.

Я немного поразвлекался с Wwise и хочу сохранить этот опыт в виде небольшого курса. Начнём с того, зачем вообще нужна отдельная программа для игрового звука, если Unreal уже умеет его воспроизводить. Затем разберём отношения разработчика и звуковика, выберем версии инструментов и доберёмся до официального проекта примеров Gyms.

Это введение для разработчика Unreal, который хочет разобраться в аудиоинтеграции, и для звуковика, который начинает работать с движком. Достаточно уметь открыть проект Unreal, найти Content Browser и запустить Play. Знание C++, Git и Python на старте не требуется.

## Что получится

После курса ты сможешь объяснить назначение Wwise, осмысленно сравнить его с FMOD и средствами Unreal, составить связку совместимых версий и пройти подготовку Gyms. Если что-то сломается, сможешь отличить проблему компилятора от отсутствующего SDK, исходного звука или банка.

Практический результат установочного блока — воспроизводимый звук в примере `EssentialPostEvent`. Инструкция пока проверена по исходникам и документации, **полное прохождение установки и прослушивание ещё предстоят**. Точные неподтверждённые места перечислены в заметках автора.
