# 3. Как состыковать Unreal, Wwise и ветку Gyms

Перед скачиванием полезно выписать версии. «У меня стоит Wwise» недостаточно: редактор звука может быть одной версии, SDK — другой, а интеграция вообще предназначаться для другого Unreal.

## Пять частей одной связки

| Часть | Зачем нужна |
| --- | --- |
| **Audiokinetic Launcher** | Устанавливает Wwise и помогает интегрировать его в проект |
| **Wwise Authoring** | Редактор аудиопроекта: события, поведение, микс и подготовка данных |
| **Wwise SDK** | Заголовки и библиотеки звукового движка для сборки интеграции |
| **Wwise Unreal Integration** | Плагины, связывающие Unreal с Wwise |
| **Gyms** | Набор учебных примеров и тестов, использующих интеграцию |

Gyms не поставляет готовую интеграцию вместе с собой: её нужно добавить. Пакет интеграции тоже не следует считать заменой установленного SDK. Эти границы описаны в [README Gyms](https://github.com/audiokinetic/Gyms/blob/d4dd88e5df3af627bc74e63fa2ea6bca2ac1a164/README.md) и [документации установки интеграции](https://www.audiokinetic.com/en/library/edge/?id=installation.html&source=UE4); для второй ссылки обязательно проверь версию страницы.

## Выбор от своего Unreal

1. Узнай версию проекта Unreal. Для существующей игры зафиксируй также патч, например `5.6.x` с реальным последним числом из редактора.
2. В Audiokinetic Launcher и release notes **конкретного выпуска Unreal Integration** найди поддержку своей версии UE. Год в названии Wwise сам по себе её не доказывает.
3. Для первого опыта выбери соответствующие этой интеграции Authoring и SDK одного выпуска и build. Так меньше независимых переменных при диагностике.
4. Открой список веток [официального Gyms](https://github.com/audiokinetic/Gyms/branches). Для семейства Wwise `2025.1` рассматриваем `main_25.1`.
5. Прочитай README именно этой ветки и проверь `Unreal/Gyms.uproject`. Убедись, что требования примеров пересекаются с поддержкой выбранной интеграции.
6. Запиши ревизию Gyms. Ветка обновляется, а SHA коммита указывает конкретное состояние файлов.

**Ветка Gyms выбирается по семейству Wwise, а совместимость с Unreal проверяется отдельно.** Название `main_25.1` не означает «для любого Unreal с Wwise 2025».

Если интеграция не поддерживает твой UE, ищи другой документированно совместимый выпуск интеграции и Wwise. Если его нет, выбирай отдельную поддерживаемую версию движка для лаборатории. Переключение `EngineAssociation` не превращает несовместимый код в совместимый.

## Набор для этого черновика

| Компонент | Целевое значение | Что подтверждено на 23.09.2026 |
| --- | --- | --- |
| Windows | 11 x64 | Условие практического маршрута |
| Unreal | 5.6 | В проверенном `Gyms.uproject` стоит `EngineAssociation: 5.6`; локальный запуск не выполнен |
| Wwise Authoring и SDK | 2025.1.11, build 9262 | Значение из исходного материала; точные требования этого выпуска независимо не подтверждены |
| Unreal Integration | Выпуск под выбранные Wwise и UE 5.6 | Полный номер и доступность нужно зафиксировать в Launcher до установочного прохода |
| Gyms | `main_25.1` | README заявляет Wwise 2025.1 и его minor releases, а также три последних версии Unreal |
| Ревизия Gyms | `d4dd88e5df3af627bc74e63fa2ea6bca2ac1a164` | Получена через официальный GitHub API при подготовке |

Здесь подтверждено соответствие семейства Wwise ветке и указанная в проекте версия Unreal. **Полная связка `2025.1.11.9262 + Integration + UE 5.6` пока остаётся кандидатом для проверки**, а не проверенной конфигурацией. Точные versioned-страницы Audiokinetic не удалось прочитать. Подменять этот пробел советом «ставь самое новое» я не буду.

Сам файл `Gyms.wproj` в этой ревизии содержит метку сохранения `v2025.1.3`, build `8968`. Она описывает сохранённый проект; из неё нельзя вывести номер необходимой интеграции или автоматически отвергнуть другие выпуски семейства. Возможную конвертацию при открытии новой версией проверяем на отдельной копии.

## Что записать перед стартом

```text
Windows:
Unreal, включая патч:
Wwise Authoring, включая build:
Wwise SDK:
Unreal Integration, полный номер:
Gyms branch:
Gyms commit:
Python и NumPy:
```

Сохрани это рядом с учебным проектом. Через месяц такая записка полезнее воспоминания «тогда вроде всё работало».

Источники конкретных значений: [Gyms.uproject](https://github.com/audiokinetic/Gyms/blob/d4dd88e5df3af627bc74e63fa2ea6bca2ac1a164/Unreal/Gyms.uproject), [Gyms.wproj](https://github.com/audiokinetic/Gyms/blob/d4dd88e5df3af627bc74e63fa2ea6bca2ac1a164/WwiseProject/Gyms.wproj).
